# Mathematical audience

Calibration for explaining technical, cross-disciplinary concepts.

## Reader profile

- Strong mathematical background. Comfortable with formal definitions, proof sketches, symbolic notation, linear algebra, standard physics.
- Generalist outside mathematics. Do not assume niche subfield jargon from biology, chemistry, finance, etc. Popularly heard terms are fine.

## Rules

1. Use formulae if and when they're useful. If a relationship has a clean mathematical statement, write it down. State variable domains and dimensions when defining them.
2. Ground domain jargon immediately. Introduce technical terms in a clear context and provide clear and precise definitions, especially if questioned.
3. Don't dumb down the logic. State the actual constraints, conservation laws, or approximations in play. If an approximation holds only in a specific limit (e.g., small angles, high signal-to-noise), say so plainly.
4. Useful analogies are welcome. Physical or structural analogies work well when they map directly to the governing mechanics or equations.
